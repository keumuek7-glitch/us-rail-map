# 미국 대륙횡단철도 노선 지도

미국 대륙횡단철도 노선을 한눈에 비교하는 인터랙티브 벡터 지도입니다.

- **현재 암트랙 여객 노선 (4개)**: 엠파이어 빌더, 캘리포니아 제퍼, 사우스웨스트 치프, 선셋 리미티드
- **19세기 역사적 횡단철도 (5개)**: 1869 퍼시픽 철도(황금 스파이크), ATSF, 서던 퍼시픽, 노던 퍼시픽, 그레이트 노던

노선을 고르면 운영사·개통 연도·거리·소요 시간, 경유역 순서, 역사적 배경이 표시됩니다. 마우스 휠로 확대/축소, 드래그로 이동할 수 있습니다.

## 배포

외부 라이브러리 없는 단일 `index.html`입니다. Netlify에 이 저장소를 연결하면 그대로 배포됩니다(publish 디렉터리 `.`).
